# AI Strategy View

Workmatik tool that joins the Excel files from the other Workmatik AI tools into one view and a suggested sequence: where AI applies (AI Roles Assessment), which workflows to start with (AI Workflow Assessment), which capabilities must be fixed first (AI Capability Assessment) and where skills need building (AI Skills Assessment and Marketing Skills Map).

Load any combination of files. Sections appear for the files you load. Everything is read in your browser. Nothing is sent or stored. Download the result as Excel.

The sequencing rules, thresholds and the link from capability categories to skill domains are the author's draft judgement and have no published source. Thresholds can be changed on the Rules tab.

Live address: https://scottstockwellworkmatik.github.io/ai-strategy-view/
